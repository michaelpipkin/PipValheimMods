# Valheim item list

Every item in the game, as the game itself reports them, for looking up the name to put
in `Pip.AutoPickupIgnorer.cfg`.

**Display name** is what Valheim calls the item on screen. **Prefab name** is what the config
file wants. They are often different, and sometimes not obviously related.

Some display names cover more than one prefab - several Black Metal Swords, several
Arbalests - and those are listed together. They are genuinely different items as far as the
game is concerned, so ignoring one does not ignore the others. If you are not sure which you
are picking up, add all of them.
